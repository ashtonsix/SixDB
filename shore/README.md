# Shore

Binds SixDB to the external world: UI, shell, SDKs and language bindings,
connectors such as S3, adapters for Arrow/Parquet and other formats, and
utilities such as exporting the entire database to a serialized format.

Successor to `~/calico-ui/`. [Engine](../engine/README.md) owns the main
query interface and database core.

Integration contracts and the shape of these tools will develop through
[Workbench](../workbench/README.md).
