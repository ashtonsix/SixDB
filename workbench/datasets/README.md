# Datasets

Dataset references, generators, and preparation scripts for experiments and
benchmarks. Workloads are broad; no fixed corpus matrix has been chosen.

Reuse existing datasets in Calico's `calico-fleet-artifacts` S3 bucket rather
than paying for duplicate storage. New dataset references and preparation
recipes will be added as studies need them. Dataset identities, local caching,
and artifact-recording details are still to develop.
