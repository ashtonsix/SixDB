# Native composition and regions

This part of the composition study asks how native fragments, drivers and
consumers fit together: traversal ownership, original coordinates, active masks,
output extent, carrier choice and retained state.

Start with the [seam findings](findings.md), [grain/carrier spectrum](spectrum.md)
and [partial-materialization contract](partial-materialization.md). The latter
retains both protected-source/output proof and the rejected general driver's
code growth and suffix losses. [Carrier probes](carriers/README.md) isolate the
cost of keeping reductions in different register forms.

The [completed composition review](evidence/delivery-composition-20260911/review.md)
places those probes in the current implementation. Ordinary arbitrary-range
traversal and stores now have [their own study](../../seriespack-range-execution/README.md).
