# Checked admission and trusted call boundaries

What state should cross a hot callback after rich validation and target selection
have already happened? The [decoder](decoder.md) and [encoder](encoder.md)
findings examine argument simplification; [point binding](point-binding.md) and
[checked get](checked-get.md) distinguish reusable trusted endpoints from
per-call checked admission.

Retained evidence includes short-call regressions, selected effect coverage and
uninstalled alternatives. Identical instructions do not imply identical timings:
[executable placement](../../executable-placement/README.md) owns that discriminator.
The current public surface is described in the
[SeriesPack reference](../../../../ikea/seriespack/reference.md).
