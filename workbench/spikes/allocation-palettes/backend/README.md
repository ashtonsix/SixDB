# Experimental finite geometry

Snapshot of the configurable allocation candidate, before production returned
to the selected fixed 15-class / 16-home layout. [snapshot.json](snapshot.json)
identifies the source bytes and the namespace-only change. The corresponding
full captured sources are recoverable from the [native evidence](../README.md).

This backend lets the same controller compare literal 16/32 classes, byte
partitions, packing and policy granules. It owns its VM mappings and typed masks;
it does not replace or link the production FiniteGroup. Changes here are new
experimental candidates, not automatic updates to Orbital.

The real production allocator is measured by the public Loom consumer.
[The geometry check](../backend_check.cpp) qualifies this experimental backend;
Orbital's finite/profile/preparation tests qualify production separately.
