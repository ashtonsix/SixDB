# Ikea Frame, phase 3

The first read/build implementation is in [`ikea::frame`](../../../ikea/docs/frame/usage.md).
Combined native qualification is in progress; the [landing receipt](GRADUATION.md)
records the exact source, checks, control comparisons and remaining limits.

The accepted foundation composes intervals (sizes or relative ends), bounds and
SeriesPack packing over non-null u64 values. Canonical descriptions, explicit
stream domains, granted immutable images and checked readers are separate from
fitting policy, placement and owner publication. Engine can steer recipes and
later extend stages/operations. Private preparation and point mutation are
excluded from this initial implementation.

The small remaining frontier is write architecture/private preparation, Engine's
choice of recipe against a real native alternative, points and dispersed work,
and executable additional stages (including TuplePack/shared records, RLE and
physical head planes). The prototype writer and its read driver remain frozen
research/control material; consumers use the Ikea implementation.
