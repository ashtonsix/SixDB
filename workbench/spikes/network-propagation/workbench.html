Online decisions and resource limits

Shared resource demand

Average occupancy over the first seed’s full drain interval, integrating configured capacity changes. TX and RX are separate full-duplex pools. Distinct logical edges can consume the same WAN pool. Momentary utilization may be much higher.

Charge ledger per object

Decimal GB tariffs are applied to modeled wire bytes. API charges apply once per object/response route, never once per simulation chunk. Fixed provisioned-link costs are separate.

Model, scope and reproducibility

Delivery means bytes available at the named recipients. It does not establish persistence, admission, clearance, service eligibility or read consistency. Eligible holders and permitted relay locations are inputs.

Chunks transmit FIFO within each object/edge stream. Active streams share sender TX, receiver RX, route capacity and shared uplinks using weighted max-min fairness. CPU work is non-preemptive per chunk; metadata jobs precede queued bulk jobs. Framing assumes IPv6, UDP, WireGuard-style padding and application headers. The model omits TCP congestion control, kernel scheduling, real transport windows, connection setup, and actual encryption measurements.

Jitter is synthetic and partly correlated by origin/destination zone and object. Percentiles describe these finite synthetic runs, not measured cloud tails or confidence intervals. A blackhole consumes full transmitted bytes; completed chunks survive at recipients. Repair sends a real modeled missing-chunk request and duplicate response traffic, after a fixed timer.

Price-only is a deliberately limited baseline: it ignores latency. Price + latency searches legal tree reparentings using capacity, pipeline and queue proxies, then simulates its shortlist with separate planning arrivals. It selects the cheapest candidate within an explicit latency allowance. Mean recipient completion and depth break residual ties. Search is bounded and does not establish a global optimum. Cost-tree is a rooted directed minimum-edge-cost arborescence for the chosen static graph. Optional-relay pruning is only a heuristic. Shortest uses unloaded whole-object edge delays. Bounded greedily reduces cost while retaining a static per-target delay stretch. Neither optimizes simulated queueing globally. See the spike README and FINDINGS for assumptions and commands.
