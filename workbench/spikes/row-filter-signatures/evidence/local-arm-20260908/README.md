# Local ARM evidence, 2026-09-08

Selected evidence for the [first resident study](../../FINDINGS.md).
The five runs retain 354 comparisons and 1,770 individual repetitions.
All use Clang 21.1.8/C++23, Google Benchmark 1.9.4, generic tuning with NEON,
pinned Linux guest CPU 0, sequential repetitions, and a 0.02-second minimum
manual-time setting per repetition. These are warmed local OrbStack ARM runs;
VM cache/frequency reports do not establish physical cache tiers.

| Run | Rows | Data / hash seed | Comparisons | Purpose |
| --- | ---: | --- | ---: | --- |
| [confirmation](confirmation/summary.md) | 1,048,576 | 41 / 13 | 158 | Cheap-predicate controls, equal-information widths, shared masks, rollups, correlation, ranges, construction and replacement |
| [hash-control](hash-control/summary.md) | 1,048,576 | 41 / 71 | 56 | Change hash independently; preserve logical data and query answers |
| [rollup-layout](rollup-layout/summary.md) | 1,048,576 | 41 / 13 | 62 | Interleaved versus contiguous summary planes; revisit controls with the extended implementation |
| [text](text/summary.md) | 65,536 | 41 / 13 | 54 | Original accident descriptions, long synthetic text, exact cached terms, construction, and smaller-population rollups |
| [data-and-or](data-and-or/summary.md) | 1,048,576 | 93 / 13 | 24 | Change scalar data independently; test `(A AND B) OR C` with rare and broad branches |

Each directory contains `samples.csv` (individual measurements),
`accounting.csv` (separate logical work/storage/answer counters), derived
`summary.csv` and `summary.md`, `provenance.json`, and `artifact.json`.
The provenance records exact selection, compiler flags, input size, affinity,
source identity, and compact-file checksums. The artifact reference identifies
the full content-addressed S3 bundle, including source archive, measured
binaries, compile commands, raw benchmark output, semantic-model output,
correctness logs, and run receipt. Full raw logs are not duplicated in Git.

The first two runs share source digest `e8cfc212ad49…`; the last three share
`07395a83a68d…`. The latter adds planar joint summaries and their checker
coverage. Full digests and source-archive checksums are in each provenance.
All retained versions include prepared/fused tag comparisons, the strengthened
native range control, and removal of redundant outer loops from flat scans.
Earlier exploratory timing screens are superseded. Findings documentation was
written after the captured measurements; the checked-in implementation matches
the final three runs' captured implementation byte for byte.

The text input is the shared dataset's 65,536 accident descriptions, preserving
original UTF-8 bytes, ordering, and duplicates. Its length-prefixed adapter is
identified by the run receipt and restored through `input-artifacts.json` in
the full bundle. Synthetic inputs are regenerated from the captured generator
and recorded seeds. A query target's frequency is not silently inferred from
the generator's combined target rate: actual true-match counts are retained.

```sh
python3 workbench/tools/artifacts.py fetch \

  build/recovered/row-signatures-example

python3 workbench/spikes/row-filter-signatures/analyze.py \
  build/recovered/row-signatures-example
```

Use `orb -m ubuntu` from macOS for Linux execution. Recovery requires the
configured artifact credentials and a new ignored output destination.
[Probe commands](../../probe.md#run-and-select) select fresh measurements;
the exact selections for these runs are in their provenance. To reproduce an
older implementation, use its captured source rather than today's checkout.

## Verification performed

All five full bundles were uploaded and downloaded with size/SHA-256
verification before compact evidence was installed. All five compact tables
were regenerated byte identically from their repetitions and accounting.
The analyzer checks complete selection, repetition identity, denominators,
oracle status, and errors. Cross-run checks also verified:

- Equal-information tag layouts and rollups retain the same row candidates.
- Planar versus interleaved summaries retain identical answers, candidate
  counts, block skips, logical group visits, and allocated metadata bytes.
- Changing only the hash preserves fixture digests and exact query answers.
- Broad versus clustered rows preserve true/candidate counts while changing
  physical group visits.

The full text bundle was separately fetched into ignored output, its input
restored, and its optimized checker executed successfully. Regenerating from
the restored raw measurements reproduced the retained tables byte identically.
Its captured implementation was compared with the current implementation.
Disassembly inspection confirmed native vector comparison/narrowing and
bit-enumeration instructions; no PMU measurements were collected.

The final text-enabled checker passed **26,738** complete-mask, boundary, tail,
text, and replacement/rebuild checks, both optimized and with ASan/UBSan.
The independent Python model passed **216 Boolean, 736 rollup, 1,449 range,
and 204 history** checks. `semantics.json` and checker outputs are in the full
bundle. These validate the implemented scope; NULL-aware SQL execution,
concurrent visibility, rollup maintenance, and recovery are not implemented
by the timed kernels.
