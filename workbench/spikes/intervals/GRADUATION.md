# Maintained Intervals integration

Ashton asked Ikea LEAD to drive Ikea HELPER through graduation, including Frame
suitability. The maintained ownership move landed in `8f710eb0`, rather than extending sparse
tuning. The [bar-raiser qualification](RAISE-BAR.md) and [earlier findings](FINDINGS.md)
remain the comparison: retain typed/fused work and carried ranges, the serial
default and explicit independent G64 prefix; reject the losing inverse and generic
value wrappers. The native recheck below measures the actual ownership move.

Common ordered search, interval geometry, native kernels, sparse sources and
borrowed edits now live in maintained `ikea::intervals`. Ordered sources need only
`size()` and ordered `at(rank)`; interval geometry separately adds an origin and
coordinate law. Engine's arbitrary-width logical keys retain exact comparison,
physical upper/lower distinctions and coherent Scope lifetimes.

StreamPack owns its compact image preparation, readable tails, count/extent,
bitmap allocation, retirement, legacy/current decoding and value operations.
Existing compact typed bodies now live under its internal geometry implementation;
Intervals does not gain an owning layout, bitmap or retirement API. The initial
move retained transitional Boundlist headers/target. The subsequent
[audit](AUDIT.md) removes that public compatibility and retires the old runnable
spike; useful tests and controls use their actual owners. Historical measured
source remains recoverable.
Persisted bytes and format discriminants are preserved, not retagged.

Frame's immutable u8 ends-minus-one projection retains exclusive endpoints up to
256 in a wider working domain, tiny counts, borrowed projected/decoded sources,
prepared windows and stable duplicate/zero-size ranks. One-bit coarse block
selection happens before descriptor/geometry/body access and is distinct from an
operation's rank filter, NULL and presence. Signed prediction and delta exception
reconstruction stay with Frame. Retained images and checkpoint choices coexist;
prepared work borrows the original coherent owner until completion.

Ikea HELPER owns Intervals/StreamPack/CMake/module documentation and checks.
Engine LEAD owns Directory integration and actual Object-shape tests. Ikea LEAD
owns Frame's actual readers, coarse filtering and lifecycle. No generic wrapper is imposed on stronger
complete consumer paths.

nine shapes are 0.974–1.008 (AVX2),0.984–1.030 (AVX512),0.993–1.019 (V2). A stricter
linked-code audit finds all 60 emitted StreamPack callbacks/profile—20 concrete

instruction encodings **and the same linked addresses** before/after. No operand
or relocation normalization is used for that byte-encoding comparison. The
namespace/ownership move adds no callback instruction, call, spill or loop work.
These facts do not imply identical timings or uniform improvement elsewhere.

All cells, including the largest observed after/pre loss (V2 u16 G32 inverse,
10.201→11.086 ns,8.7%), remain in the tables. Panel median ratios are near 1.0;
this does not erase individual losses or identify their cause. This migration
introduces no wider default, generic payload wrapper or new representation bytes.
