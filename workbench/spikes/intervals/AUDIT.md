# Intervals graduation follow-through

Ashton found that the first graduation left documentation well below the old
Boundlist guide and retained its public compatibility module. He extended the
audit to other missed consequences, live caller performance, linked disassembly
and decisions about how each consumer should use the seam. This closes that
follow-through; the original [graduation](GRADUATION.md) and
[G64 performance study](RAISE-BAR.md) retain their own source epochs and limits.

The ownership split remains implemented: Intervals owns borrowed search, geometry,
source interpretation and kernels; StreamPack owns its compact format, count/extent,
bitmap/retirement, U, payload and coordinated writes. Sparse sources introduce no
persisted schema. All 41 maintained Intervals/StreamPack implementation files are
byte-identical to the qualified graduation source; this cleanup changes the public
compatibility/build/documentation routes, not their read or mutation bodies.

The audit checked signed/wider comparisons, exact K-byte logical domains,
duplicate/zero-rank identity, excluded physical owners, exact bitmap tails,
initialized native/checkpoint grants, strided siblings, prepared-source lifetimes,
source-qualified damage, refusal before stores and legacy/current byte laws.
Frame block selection still precedes descriptor/geometry/body access; it is not
an entry-rank filter, NULL or presence. Signed predictor/exception reconstruction
remains Frame's algebra rather than unsigned interval sizes.

## Actual linked Directory and StreamPack

The first audit cohort runs actual Directory reads against the frozen pre-graduation
source and maintained code on the same worker, in before/after/after/before process
order. The driver and underlying Engine, Orbital and Loom sources match after only
the include/namespace and comment spelling changes. Shapes are L4/J0 at16,384 and
1,048,576 entries, and L3/J4 at1,048,576; each has32,768 requests and seven inner
repetitions. Its CSV retains per-process median/minimum, not raw inner trials.

All seven emitted read functions—physical route/lower, find, next, physical/logical
seek and dirent—have identical encoded instructions **and linked addresses** on
Zen5 AVX2, Zen5 AVX-512 and V2 NEON:21 comparisons. This extends the earlier local
O2 object proof; it does not imply identical runtime. V2 after/before medians range
0.981..1.018, AVX2 0.967..1.109 and AVX-512 0.787..1.006. Both losses and gains
remain; this audit does not isolate allocation/cache/predictor/frequency causes
or attribute those fluctuations to a namespace speedup.

Current StreamPack complete value consumers cover all nine codec/full/placement
shapes, with22 rotated samples per arm. Their maintained/fused callbacks preserve
start+U specialization, liveness/rank checks, payload consumption and carrier
selection. Comparing all60 emitted callbacks per profile with graduation:
42 encodings are exact; the other18 Sizes callbacks differ in PC-relative constant
addressing. All60 x86 bodies match after resolving RIP references to their actual
constant addresses. For NEON, all27 affected16-byte mask loads were resolved from
the old/new final ELFs and their bytes match; the remaining differences are page
and load-offset relocation. Every callback moved in this relink, so these are not
claimed as identical address-placement experiments.

The code retains the native prefix and fused consumer; it adds no per-value
Intervals call or generic packet. Fresh current timings retain losses too—for
example V2 grouped Sizes start+external-U reconstruction costs2.497 ns/value
against2.155 for the maintained getter. Occasional wins through another wrapper
with the same ready body do not establish a new algorithm or replace that getter.

## Frame: complete getter, then policy

`frame-runs-generate.py` took the **actual** point/compact getter classes from
Ikea LEAD's fixed source. It changed only class/constructor names and
`fe::run_ends` to `intervals::run_end_source`, then asserted an exact inverse
transform. Both policies borrow the same original image and use the same decoding,
descriptor, checkpoint and result path. Current-tree mode instead binds the actual
curated aliases. Neither mode hand-implements a stripped RLE kernel.

The real encoder supplies widths from8/32/64-bit input domains, run counts
4/8/15/16/17/32/64/128, and1/256 blocks, plus packed non-RLE controls. It chooses
packed rather than128-run/8-bit RLE, so those two cases are recorded as skipped;
the remaining52 cases qualify. Every row is compared with original input, then
C1 and eight independent decoded-value request streams are checked against a
plain-input oracle. Each next address depends on its decoded value.

The corrected trace adds deterministic independent per-request salts (64 KiB)
to prevent short cycles/coalescence. Audited coverage is256 distinct rows for a
one-block image and7,659..7,752 for8,192 requests over256 blocks. The salts are
part of the measured request work and footprint. `image_bytes` counts encoded
payload plus descriptors; it excludes decoder bindings, other column state and
RSS. Both policies borrow the same complete owning image. Seven rotated trials in each of
two reversed-order processes retain14 samples for every cell. These are warm
small-image native measurements, without a DRAM/cache-residency or cold-service
claim; C8 means eight streams in the actual emitted getter/call loop, not a claim
of eight simultaneously outstanding misses.

Example: **16 runs,32-bit input domain,256 blocks**, ns per complete point request:

| Profile | Bound C1 raw → native | Bound C8 raw → native | Compact C8 raw → native |
| --- | ---: | ---: | ---: |
| Zen5 AVX2 |16.698 →9.877 |16.301 →5.662 |14.304 →5.727 |
| Zen5 AVX-512 |16.755 →10.353 |15.194 →5.803 |14.802 →5.926 |
| V2 NEON |24.249 →17.360 |21.388 →7.548 |21.248 →6.904 |

All336 native-policy cells with at least16 runs improve in this cohort. Native/raw
ratios span0.236..0.674 on AVX2,0.203..0.686 on AVX-512 and0.318..0.916 on V2.
All1,248 total cells and17,472 raw samples remain, including tiny and non-RLE
losses. For example, unchanged packed bound C8 on AVX2 moves3.088 →3.449 ns in
the32-bit/256-block case. Its data path does not use run search; whole-getter/code
placement effects still matter. Tiny raw/native bodies share the comparison
projection, and their small wins/losses do not earn another policy switch.

### Disassembly and microarchitecture

The linked getter/request bodies, not isolated prefix functions, were inspected
on all three profiles. V2's generic RLE search has serial midpoint loads and a
query-dependent `b.ls` at each decision. Native search converges with conditional
selects, then a16-byte load/`cmhi`; NEON forms its mask with weighted lanes, two
`addv` reductions, vector-to-GPR moves and `rbit`/`clz`. AVX2 uses unsigned-order
translation, vector compare, `vpmovmskb` and trailing-zero selection. AVX-512 uses
wider unsigned predicate comparisons, `kmov` and trailing-zero selection. The
reduced serial decisions are consistent with the unpredictable-request gains;
no measured branch-miss count is inferred from that explanation.

Costs remain visible. V2's bound getter grows280 →336 instructions, including
padding; compact grows256 →304. The bound getter still pays the existing delta
scratch-stack prologue even for RLE; the compact program avoids that large scratch
frame. C8 calls each actual outlined getter eight times, with saved state/spills;
it is not an inlined array-scan surrogate. The code size, mask/reduction work and
predictable scalar path explain why a globally native policy is not warranted.
Straight-line MCA would not model the decisive query-dependent branch behavior;
its earlier G64 resource diagnostics remain separately qualified.

### Preserve the first trace as a diagnostic

The first cohort used an unsalted deterministic next-address function. It passed
value/checksum checks but visited only7..81 distinct rows for one block and
77..1,283 for256 blocks. Independent replay reproduces all11,648 Zen5 timing-record
checksums and records that coverage. It is not a representative random-request
comparison. It remains a separately labeled low-entropy/predictable control,
including native C1 losses, rather than disappearing after the favorable rerun.
Its Directory and StreamPack panels are independent of that Frame trace flaw.
