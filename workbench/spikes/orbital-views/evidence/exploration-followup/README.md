# Backing, journal service and completed-cut follow-up

Job `20261005T133105Z-a23848be` completed successfully on the same reused Spot
c8a.2xlarge as the [main comparison](../exploration/README.md). CPU 0 runs the
serial studies; completed-cut workers pin distinct CPUs 0–3. Pinned Clang 21.1.8,
Zen5 targeting and the main host context apply. The worker was terminated after
collection; AWS state was independently checked.

- **48 backing cells × six trials:** same selected immutable payloads, separate
  parts versus shared chunks, including dispersed/localized retention. The
  benchmark explicitly raises its own soft FD limit from 1,024 to 1,088 within
  the existing hard limit; this permits pricing the failing baseline, rather
  than recommending that production merely raise its limit.
- **18 journal cells × six trials:** real writes and `fdatasync`, concatenate
  versus gathered buffers, payload sizes 64/4,096/65,536 and batches 1/16/64.
  `filesystem.txt` records ext4 on root gp3. Timings exclude batch-fill/queue
  waiting and frame construction; maxima are service batches, not percentiles.
- **24 completed-cut cells × six trials:** shared progress versus separated
  producer counters, with actual immutable bytes, sums and historical reads.
  Strict producer-local order is supplied; arbitrary local holes need more state.
  Fixed interleaved epoch IDs are supplied too; reported ns/publication measures
  aggregate wall-time throughput, not individual request latency.
- **Actual-I/O composition:** old cuts survive working-home reuse; a fresh process
  recovers epoch 3 while material stalls; reversed/failing background transfers
  leave the epoch 5 consumer head intact. This uses serialized ownership and
  replayable afterimages, not semantic intent or consensus.

Summaries retain medians/ranges and work counters. [Systems comparands](../../systems/README.md)
and [cut comparands](../../control/cut.md) explain their limits. Logical backing
sizes are not RSS/device traffic; sealed-chunk retention is not an unavoidable
property of a shared file with independent extents.

source capture, compiler output and the targeted runner. The golden
