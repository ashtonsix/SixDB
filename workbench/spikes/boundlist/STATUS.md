# Boundlist close-out

This records the closed prototype study. Subsequent authorized production work
and qualification are tracked in [IMPLEMENTATION.md](IMPLEMENTATION.md),
[GRADUATION.md](GRADUATION.md) and the current
[geometry/value ownership assessment](OWNERSHIP.md).

Authorized outcome: run the spike in main without commits and make a simple
recommendation on what should promote to Ikea. At this prototype close, the recommendation and selected native evidence were
complete; production migration followed in the linked implementation report.

## Recommendation

Extract the existing Direct/Width metadata formats and compact access bodies
into `ikea::boundlist`. Add reusable ordered boundary/range search and typed
checkpoint/local-window composition. Preserve StreamPack physical reverse,
optional U/D, fixed/full/immortal recipes, source effects and readable tails.
Do not promote the experimental algorithm menu, flattened adapter, generic paired
Width prefix or a universal lerp/scan/paid-guide policy.

See [RECOMMENDATION.md](RECOMMENDATION.md) for the small surface, dependency
ownership and implementation boundary; [FINDINGS.md](FINDINGS.md) gives timings,
memory and material limitations.

## Boundaries carried into implementation and Engine

Production module extraction, standalone headers/admission/effects/API examples
and complete StreamPack regression qualification remain implementation work.
The prototype adapter has real modest reader losses and is not selected unchanged.
No writer speedup, selective geometry-sharing economics, Neoverse V3/SVE2 result
or universal DRAM-service claim is established.

Engine owns the full mutable index/directory policy, split/merge/rebalance costs,
64-byte dirent/Part routing and coherent owner publication. Search/extraction/grant
findings were handed over directly. This spike has not implemented or benchmarked
a complete new mutable index. Caller-hint galloping, more elaborate bounded
interpolation and universal per-consumer cutoffs remain unselected experiments;
they are not prerequisites for the recommended extraction.

The [original plan](PLAN.md) records a broader candidate space, not a claim that
every proposed experiment was needed or performed. The current recommendation
closes the authorized spike; it does not silently graduate those proposals.
