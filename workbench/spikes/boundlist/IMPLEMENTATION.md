## Selected architecture

One ordered lower/upper/overlap contract serves native endpoints, G16 widths,
reservation metadata and custom packed/ordered domains. Population is independent.
Unique exact-max routing uses one search. Local count is unsigned/UINT_MAX; there
is no universal64-bit key or metric requirement.

Ordinary native search uses conditional-select bisection and bounded SIMD
convergence. Opt-in hot scans and genuinely interleaved batches remain. Numeric
binding caches source preparation and privately selects a checked interpolation
bracket: N>=4096, bracket32..128 and bracket*32<=N. Both edges are verified before
narrowing. Duplicate alias and long-run counterexamples constrain admission.
Point wins are broad; AVX-512 range losses keep numeric binding opt-in. Raw sources
remain the default. Immediate and suspended completion share the same laws.

The reservation recipe keeps its8B version2 description,256 ranks, Direct/Width,
G16 and useful omitted-fact schemas. StreamPack extends Boundlist's16B typed
metadata access with payload work; original named-source effects map metadata
planes0/1/2 to StreamPack1/2/3. One law owns append, packing and validation.
The Width sidecar proves16 checkpoints readable; generic Width sources prove
only assigned checkpoints. Raw geometric phases are16B snapshots borrowing
backing, while population phases also borrow their named source/access. Hint
windows are not complete read/protection grants.

StreamPack keeps one36-line payload-admission/validation TU. Its old schema TU,
three private forwarding headers, duplicate schema switch and unused core link
dependency are removed. Basic views avoid search/native kernels. Public names,
wire bytes and metadata footprint are preserved. Boundlist owns the stored-byte
specification; StreamPack documents its payload composition. Historical private
benchmark references follow the helper's actual owner and compile.
