# Open questions

For related experiments and prior work, start with the
[research map](README.md). The question routes now hold the cross-study
connections formerly collected on this page. Loose leads can remain notes
indefinitely; these are opportunities, not a queued campaign.

- **Index maintenance:** when can append contributions, idempotent dirtiness
  and live geometry avoid eager numerical folding? The
  [maintenance route](indexes-and-maintenance.md#avoiding-per-write-ancestor-work)
  joins the original counterexamples to the current consumer.
- **Persistent plans:** how do retained equivalence graphs, changing costs and
  periodic probes improve work already in progress?
  [Representations and planning](representations-and-planning.md#plans-that-keep-improving)
  preserves the proposal, semantic questions and executable-placement qualification.
- **Execution grain:** where should native fusion end and shared orchestration
  begin, while independent memory work and owner service still make progress?
  [Execution and code generation](execution-and-codegen.md) connects the probes.
- **Representation and lifetime:** what should be shared, retained, rebuilt or
  converted at each actual reuse boundary?
  [Memory and lifetimes](memory-and-lifetimes.md) separates logical authority,
  interpretation and physical ownership.
- **Secondary summaries:** which questions need proof of absence, selectivity
  estimates or approximate answers? [Sketches, filters and histograms](secondary-summaries.md)
  keeps those contracts separate; the meaning of “min-sketches” remains open.
- **Residual bounds:** which extrema/refinement mechanisms serve a concrete
  caller rather than an encoding objective in isolation?
  [The bounds note](pfor-bounds.md) retains promising ideas and their failures.
- **Reproducible relinking:** when would selected objects, archives and link
  commands repay retention? [Executable recovery](../spikes/executable-placement/layout-recovery.md)
  records the repeated reconstruction cost, without proposing universal build retention.
- **Customer outcomes:** which technical advantages justify adoption and an
  enduring paid offer? [Commercial questions](commercial.md) connects this to
  [teams and shared authority](sociology.md).

Broader [Orbital questions](orbital-ideas.md), [Loom objectives](loom-objectives-and-architecture.md),
[transaction histories](transactions/README.md), [dataflow workloads](dataflow-workloads.md)
and the [dissemination survey](dissemination/README.md) retain their own open space.
