# Workbench

A place for science and a Swiss army knife for anyone working on SixDB.
Design develops here first, through investigation, experiments, and spikes.
Successor to Calico's `workbench`.

| Path | Purpose |
| --- | --- |
| [design/](design/README.md) | Developing design notes and open conventions |
| [prototypes/](prototypes/README.md) | Experiments and spikes |
| [benchmarks/](benchmarks/README.md) | Benchmark programs and measurement helpers |
| [tools/](tools/README.md) | Scripts, provisioning, and artifact tooling |
| [datasets/](datasets/README.md) | Dataset references, preparation, and generators |
| [prior-art/](prior-art/README.md) | Index of relevant mechanisms, sources, and earlier evidence |

The process for recording experiments, interpreting results, and producing
design documents is awaiting Ashton’s guidance. These directories establish
places to work without imposing stages, templates, or promotion gates.
