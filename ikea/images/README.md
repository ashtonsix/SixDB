# Documentation figures

The committed SVGs are generated by [generate.py](generate.py). From the repository
root on Linux, run `python3 ikea/images/generate.py`; on macOS/OrbStack, prefix
the command with `orb -m ubuntu`.

The generator compiles a small reader with the pinned Clang toolchain to obtain
the striped maps and Local11 bytes from the current SeriesPack implementation.
Its temporary source and executable live under ignored `build/diagrams/`.
The diagrams illustrate the contracts in the guides; the C++ wire law and frozen
reference remain authoritative.

The overview and owner-lifetime figures live here. The four physical/composition
figures live in [seriespack/images](../seriespack/images). Each figure is embedded
on its owning guide, with context and captions there. Keep rejected candidates
and raster previews in ignored build output. Check the SVGs at rendered Markdown
width after changing labels or layout, including arrow direction and byte/row units.
