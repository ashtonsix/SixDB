# Documentation figures

The committed SVGs are generated by [generate.py](generate.py). From the repository
root on Linux, run `python3 ikea/docs/images/generate.py`; on macOS/OrbStack, prefix
the command with `orb -m ubuntu`.

The generator compiles a small reader with pinned Clang. It obtains striped maps
and Local11 bytes from SeriesPack's implementation, and decodes TuplePack's known
ordinary-example bytes with the current scalar body. The ordinary example also
checks construction and the public two-row projection. Temporary source and
executables live under ignored `build/diagrams/`. Figures illustrate the guides;
the C++ contracts and independent wire checks remain authoritative.

The overview and owner-lifetime figures live here; module figures live in
[seriespack/images](../seriespack/images) and [tuplepack/images](../tuplepack/images).
Each is embedded on its owning guide with context and a caption. Keep rejected
candidates and raster previews in ignored build output.

Inspect figures at rendered Markdown width after changing labels or layout.
Check arrow meaning and direction, bit order, byte/row units and text fit.
Use colour consistently within a figure and label the distinction it carries.
Exact storage diagrams need an executable check; conceptual flows must identify
their scope, especially binding versus invocation and local work versus publication.
