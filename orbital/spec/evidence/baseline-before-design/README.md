# Historical baseline before design revision

This is an incomplete historical selection, not the final verification campaign.
It records 485 accepted checks: 200 complete graphs, 151 deliberate defects and
134 witnesses. The larger Admission renewal graph was still incomplete.
Subsequent review found that the root-owner reset preserved consumed volatile
replies and reset surviving-holder suppression. These captured results establish
the narrower modeled reset, not full cold-owner recovery. The maintained design
revision corrects that gap and separately changes reservation policy/folding.

The exact pre-revision source snapshot and reports are under reference. Per-case
parsed source closures, receipts, logs and progress are under runs. selection.json
identifies their bundle paths and original inputs. Snapshot/run input identities
remain unchanged; the current collector only cloned and rehashed retained bytes.
No stopped graph is treated as a completed result. The final maintained selection
replaces affected cases using actual dependency hashes.
